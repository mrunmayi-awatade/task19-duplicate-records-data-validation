# Task 19 - Duplicate Records and Data Validation

## Overview
This task demonstrates how to identify duplicate records, remove duplicates, and validate data using Python and Pandas.

## Topics Covered
- Identifying duplicate rows using duplicated()
- Counting duplicate records
- Displaying duplicate rows
- Removing duplicates using drop_duplicates()
- Keeping the last occurrence of duplicates
- Checking missing values
- Validating age values
- Validating marks ranges
- Checking allowed categories using isin()
- Identifying invalid records
- Creating a final cleaned dataset

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## File Included
- task19_duplicate_records_data_validation.ipynb

## Outcome
Learned how to identify duplicate records, validate data, and prepare a cleaner dataset for analysis.
